# ПРАКТИЧЕСКИЙ БЛОК
# 1. Автоматизация теста к API
Разработан автотест на Python, проверяющий работу API, который создает заказ и проверяет, что по треку заказа можно получить данные о заказе

# Файловая структура
1. `configuration.py` - содержит базовый URL и пути к конечным точкам API
2. `data.py`  - тестовые данные запроса
3. `sender_stand_request.py` - реализует функции для отправки запросов к серверу
4. `test_order_by_track.py` - автотест

# Запуск теста
- Перед запуском установить необходимые зависимости (`requirements.txt`) командой `pip install -r requirements.txt.`
- После этого выполнить командой `pytest test_order_by_track.py`
- Важно: проверить, что в `configuration.py` указан актуальный адрес сервера.
